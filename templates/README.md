# תבניות מובנות

## הוספת תבנית חדשה

1. יוצרים קובץ HTML בתיקייה המתאימה, למשל `service/new-thing.html`. הדרך הקלה היא להעתיק תבנית קיימת מאותה קטגוריה.
2. מוסיפים שורה ל-`BUILTIN_TEMPLATES` ב-`lib/email.js`:
   ```js
   { id: 'new-thing', group: 'service', name: 'השם שיופיע ברשימה', file: 'templates/service/new-thing.html' },
   ```
   `group` הוא אחת הקטגוריות ב-`TEMPLATE_GROUPS` (שם אפשר גם להוסיף קטגוריה חדשה).
3. טוענים מחדש את התוסף ב-`chrome://extensions`.

## חלקים משותפים

תבניות שירות הלקוחות משתמשות באותה כותרת ואותה חתימה:

```html
<!--#include file="partials/service-top.html" -->
  ... התוכן של המייל, שורות <tr> ...
<!--#include file="partials/service-bottom.html" -->
```

מיילים שיווקיים (בתיקייה `marketing/`) נסגרים ב-`partials/marketing-bottom.html` במקום זה. החלק הזה כולל את חתימת הנציג וקישור הסרה מרשימת התפוצה, שחובה לכלול במיילים שיווקיים.

## באנרים

מייל שנפתח בבאנר משתמש ב-`partials/banner-top.html` במקום `service-top.html`. הבאנר כבר כולל את הלוגו ואת השם, לכן אין מעליו שורת לוגו נוספת. מיד אחריו באה שורת הבאנר:

```html
<!--#include file="partials/banner-top.html" -->
<tr><td style="padding:0;font-size:0;line-height:0;">
 <img src="{{תמונה: באנר ...}}" data-ghx-fallback="templates/img/banner-....jpg" width="600" height="270" alt="..." style="display:block;width:100%;max-width:600px;height:auto;border:0;">
</td></tr>
```

- הבאנרים נמצאים ב-`img/banner-*.jpg`, בגודל 600×270 (מצולמים בחדות כפולה).
- הכותרת כתובה בתוך הבאנר, ולכן לא חוזרים עליה בטקסט שמתחתיו.
- מיילים תפעוליים (חשבונית, החזר, תשלום, ביטול, הקפאה) נשארים בלי באנר.
- לבאנר חדש אין קישור ב-Drive. בעורך, ליד שדה התמונה, יש כפתור **"⬆ העלאה ל-Drive"**: הוא מעלה את העותק מהתוסף, משתף אותו וממלא את הקישור. צריך לעשות את זה פעם אחת לכל באנר.

שינוי ב-`partials/` משנה את כל התבניות שמשתמשות בהם. הנתיב הוא יחסית לתיקייה `templates/`.

## משתנים

- `{{שם}}`: שדה שממלאים בעורך או מעמודה ב-Excel.
- `{{שם|ברירת מחדל}}`: שדה עם ערך התחלתי.
- `{{טלפון#intl}}`: אותו ערך בפורמט בינלאומי, לקישורי `tel:` ו-WhatsApp.
- `{{תמונה: שם|קישור Drive}}`: שדה תמונה. אם מוסיפים `data-ghx-fallback="templates/img/..."`, מוצג עותק מקומי בתצוגה המקדימה.

ערך שממלאים נשמר לפי שם המשתנה ומשותף לכל התבניות. לכן כדאי להשתמש באותם שמות: `שם ההורה`, `שם הילד`, `מועד המפגש`, `קישור למפגש`, `טלפון השירות` וכו'.

## כפתור למסמך

חשבונית, קבלה, טופס או כל מסמך אחר מקבלים כפתור משלהם. בעורך לוחצים **"+ כפתור למסמך"**, והכפתור נכנס לפני החתימה. זה המבנה שלו:

```html
<!-- DOC BUTTON -->
<tr><td ...> ... <a href="{{קישור למסמך: חשבונית}}" ...>לצפייה בחשבונית ←</a> ... </td></tr>
<!-- /DOC BUTTON -->
```

- משתנה ששמו מתחיל ב-`קישור למסמך` מקבל בעורך שדה 📄 משלו, עם 🗑 שמוחק את כל הכפתור. זה עובד בזכות ההערות `DOC BUTTON`.
- בשליחה לרשימה אפשר לקחת את הקישור מעמודה ב-Excel, וכך כל נמען מקבל את המסמך שלו.
- כפתור בלי קישור נחשב שדה חסר: העורך מסמן אותו, ובשליחה לרשימה השורה מדולגת.

## תמונות שהוחלפו

`RETIRED_DRIVE_IDS` ב-`lib/email.js` מכיל קבצי Drive שאסור לשלוח יותר, למשל צילום האפליקציה הישן עם "שלום שמעון". קישור לקובץ כזה נחשב ריק בכל מקום: בערכים שמורים, בתבניות שמורות ובברירות מחדל. במקומו מופיע כפתור "⬆ העלאה ל-Drive".

## כותרת = נושא המייל

ה-`<title>` של התבנית ממלא את נושא המייל, ואפשר לשים בו משתנים.
